# cafe‑central‑app
## Descripción
Aplicación web para la cafetería Café Central; permite a los clientes ver el menú, consultar precios, registrarse, elegir productos, crear pedidos y saber su estado desde celular o computadora.

## Problema que resuelve
Antes los clientes debían ir al local o llamar para pedir; no tenían una forma rápida de ver el menú y enviar pedidos en línea.

## Funcionalidades principales
‑ Consulta del menú y visualización de precios
‑ Registro de clientes
‑ Selección de productos
‑ Creación de pedidos
‑ Consulta del estado del pedido

## Integrantes del equipo
‑ Karla: análisis y diseño de menú
‑ Alexa: diseño de pantallas
‑ Lesly: historias de usuario y módulo de pedidos
‑ Nahomi: diseño y programación del menú
‑ Marco: diseño de formularios y módulo de pedidos

## Tecnologías a utilizar
‑ Python + Flask
‑ HTML y CSS
‑ Base de datos SQLite
‑ Git y GitHub para control de versiones
